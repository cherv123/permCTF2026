
Получаем файлик **blob.data**

Поглядим на энтропию файла:

```bash
ent blob.data              
Entropy = 7.999982 bits per byte.
```
Энтропия высокая. 
Трайнем strings - выводится куча не особо читаемых строк.
Исходя из того что в описании говорится про комбинацию из трех слов - то вероятнее всего речь идет про цепочку из strings + grep + декодирование (base64/base32/etc). Методом тыка выясняем что все же base64:

```bash
strings -n 20 blob.data | grep -E '^[A-Za-z0-9+/=]{20,}$' | base64 -d
```

```css
permctf{b4s3+BRU7E+gr3p=S0Lv3}
```
